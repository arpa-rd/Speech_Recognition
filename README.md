# Speech_Recognition
<p>1. Run the dtw_matching.m file to recognize among six keywords (Tennis, Golf, Rugby, Soccer, Darts, Chess). <br>
  2. Run the dtw_with4.m file to recognize among four keywords (Tennis, Golf, Rugby, Soccer). <br>
  3. Run the dtwlog.m file if you want to include log energy while mfcc extraction. <br>
  4. Run the bonus.m file for detection of any unknown word. <br>
  5. Open the manual_mfcc.m file to understand how mfcc coefficients are extracted. 
  6. Features.m file extracts mfcc features excluding log energy and logfeatures.m file extracts mfcc features including log energy.</p>
